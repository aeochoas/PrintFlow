
# PrintFlow

Sistema SaaS de gestión administrativa, financiera y operativa para negocios de publicidad, personalización y producción gráfica.

## Descripción

PrintFlow es una plataforma web multiempresa que permite a negocios dedicados a DTF, sublimación, bordados, estampados, vinilos y publicidad gestionar sus operaciones desde un solo lugar.

Su objetivo es facilitar el control de clientes, pedidos, cotizaciones, ingresos, gastos y rentabilidad del negocio.

## Objetivos principales

- Administrar clientes y proveedores.
- Gestionar pedidos y estados de producción.
- Registrar ingresos y gastos.
- Controlar las finanzas del negocio.
- Generar cotizaciones.
- Generar facturas y comprobantes.
- Administrar productos, servicios e inventario.
- Consultar indicadores y reportes.
- Gestionar suscripciones de los negocios.

## Arquitectura

PrintFlow utilizará una arquitectura de monolito modular con soporte multiempresa (multi-tenancy).

El frontend se comunicará con el backend mediante una API REST.

El backend gestionará las reglas de negocio, seguridad y persistencia de información.
